## 2. Implemented Design System Specifications & Rules

### A. 20 Ways to Unslop AI Designs
1. **Delete Filler Badges:** Removed unnecessary tags, autogenerated class dumps (`u-extracted-*`), and artificial pill clutter.
2. **Drop Redundant Labels:** Stripped repeated "Status:", "Amount:", and "Order:" prefixes where spatial hierarchy and column headers clearly denote context.
3. **Unitalicize Random Words:** Cleared erratic `font-style: italic` declarations from `.dash-stat-subtext`, table headings, and `.status-pill` elements.
4. **Mono Only Where Needed:** Strictly confined monospace typography (`ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace`) to operational identifiers (`.order-number`, `.ops-mono`, parcel barcodes, QR codes). All labels, currencies, and descriptions remain proportional sans-serif.
5. **Use a Design System:** Replaced rogue royal blues (`#2563eb`) and arbitrary hex codes with EZiCart tokens:
   - Primary Accent: `--dash-primary: #be2854;`
   - Primary Hover: `--dash-primary-hover: #9f2046;`
   - Primary Soft / Tint: `--dash-primary-soft: #fff1f6;`
   - Border Subtle: `--dash-border: #f0cdd8; --dash-border-subtle: #f9eaf0;`
   - Surfaces: `--dash-bg: #fdfafd; --dash-card-bg: #ffffff;`
6. **Show the Actual Product:** Rendered real product thumbnails (`<x-order-table-products :items="$order->items" />`) in operational tables rather than abstract placeholders.
7. **Enlarge the Main Feature:** Prominently scaled the primary KPI value (`font-size: 28px; font-weight: 650;`) and courier hero dispatch banner (`courier-hero-card`).
8. **Group with Spacing:** Organized operational flows into clear 24px/20px padded panels with 16px/20px CSS grid gaps rather than harsh heavy divider borders.
9. **Make Headlines Specific:** Enhanced panel titles to be direct, communicative, and task-oriented (e.g., "Marketplace overview", "Operational queues", "Today's dispatch queue").
10. **Emphasize the CTA:** Primary action buttons (`.dash-btn-primary`, `.ops-btn--primary`) now have minimum 40–42px touch height, 600 semi-bold weight, solid primary background with subtle depth shadow (`box-shadow: 0 2px 8px rgba(190, 40, 84, 0.22);`), and distinct hover lift (`#9f2046`).
11. **Add an Accent Colour:** Unified the signature EZiCart raspberry accent (`#be2854`) harmonized with soft bubblegum pinks and cloud-white gradients.
12. **Keep Icons Consistent:** Used cohesive `<x-shop-icon>` SVG icon set sized uniformly (18px/19px) across metrics, tables, and actions.
13. **Remove Embellishments:** Eliminated harsh high-contrast saturated drop-shadows and tacky pseudo-element borders (`::before` strips on stat cards and hero cards).
14. **Inner Radius = Outer Radius - Padding ($R_{\text{inner}} = R_{\text{outer}} - P$):**
    - Outer cards & panels: $R = 14\text{px}$, Padding = $20\text{px} - 24\text{px}$.
    - Nested action cards & order items: $R = 10\text{px}$ (prevents clumsy concentric corner clash).
    - Status pills & micro-buttons: $R = 6\text{px} - 8\text{px}$ or continuous pill (`9999px`).
15. **Improve Text Contrast:** High-contrast neutral text (`#202634` / `#1c2536`) against pure white and soft backgrounds; subdued secondary metadata (`#657084`) meeting WCAG AA contrast standards.
16. **Wrap Headlines Properly:** Applied `text-wrap: balance;` to `.dash-title`, `.dash-subtitle`, `.dash-panel-title`, `.ops-heading h1`, `.courier-hero-card h2`, and `.decision-dialog h2` to eradicate orphan single-word widows.
17. **Align by Eye, Not Pixels:** Balanced icons with vertical text baselines using flex alignment and optical centering.
18. **Use Tabular Numbers:** Applied `font-variant-numeric: tabular-nums;` to `.dash-stat-value`, `.ops-stat strong`, `.dash-table`, `.ops-table`, `.order-total-price`, `.financial-amount`, and metric badges to ensure columnar stability and avoid visual jitter during updates.
19. **Add Loading States:** Added skeleton loaders (`<x-loading-skeleton variant="message-list" />`) and smooth opacity states in the message drawer and decision forms (`[data-decision-submitting]`).
20. **Animate Useful Feedback:** Incorporated `@keyframes success-pulse` on success banners and recorded feedback notifications.

---

### B. Micro-Interactions & Animation Guidelines
- **Ease-Out Entrances:** Modal pop-up (`.decision-dialog`) and drawer (`.message-drawer`) open using `cubic-bezier(.16, 1, .3, 1)` at 180ms.
- **Scale from 0.95:** Popovers and dialogs enter with `transform: scale(0.95)` to `scale(1)` to create depth.
- **Scale to 0.97 on Press:** Added tactile active press feedback (`:active:not(:disabled) { transform: scale(0.97); }`) across all primary, outline, and small action buttons for immediate tactile confirmation (adhering to the Doherty threshold < 400ms).
- **Reduced Motion Support:** Maintained `@media (prefers-reduced-motion: reduce)` disabling transitions and transforms for accessibility compliance.

## 5. Notes for Future Agents (Codex, GPT)

- **Preservation Policy:** Do not edit `home.blade.php`, `home-guest.blade.php`, `welcome.blade.php`, `search/index.blade.php`, `catalog-search.css`, or `landing.css`. These have been explicitly locked by the user.
- **Design Tokens:** Always utilize `--dash-primary`, `--dash-border`, `--dash-primary-soft`, and `--dash-radius-card` / `--dash-radius-inner` in dashboard and operational views rather than introducing raw hex values.
- **Typography Convention:** Monospace is reserved exclusively for system IDs (`.order-number`, `.ops-mono`, parcel barcodes). All currency values, dates, and metric numbers must use proportional fonts with `font-variant-numeric: tabular-nums`.
- **Button Feedback:** Any new button added to dashboards should adopt the `:active:not(:disabled) { transform: scale(0.97); }` feedback pattern.
